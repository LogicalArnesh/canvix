## What is Cramva?

Cramva is a browser-based design tool built and maintained by **Arnesh**. Create social media posts, presentations, posters, logos and thumbnails with a drag-and-drop editor. Testing by Arnesh.

## Features

- Drag-and-drop editor (desktop, tablet, mobile)
- Templates, shapes, text, images
- Export PNG / JPG / SVG / PDF
- Free accounts (username + password)
- AI features when configured
- Real-time collaboration
